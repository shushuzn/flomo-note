# flomo 卡片笔记（云端）

本地只存本文件 + AGENTS.md + .mcp.json；卡片仅存云端 flomo。

## 能力边界（一次讲清）

flomo MCP 工具（实测）：`get_daily_review` `get_format_guide` `get_tag_guide` `memo_batch_get` `memo_create` `memo_recommended` `memo_search` `memo_update` `memory_context` `memory_user` `tag_rename` `tag_search` `tag_tree`。

写操作只有三个：
- `memo_create` 新建
- `memo_update` 覆盖某张卡（整卡替换，不保留旧文）
- `tag_rename` 全库改标签名

无 `memo_delete`：删卡只能你在 App 手动，技能侧不碰、不提示。
无 `memo_merge`："合并卡片"做不到——`memo_update` 是覆盖不是并卡，`tag_rename` 只能并**标签名**不能并**卡片**。复盘说"合并"只指标签归并或内容聚合提议，绝不声明"已合并两张卡"。

## 执行铁律

1. 只读工具（memo_search/tag_tree/memo_batch_get/memo_recommended/get_* /memory_* /webfetch/websearch）直接做。**新建卡（memo_create）免确认**：抓取→查重→自检 EXIT=0 后直接写云，不展示等批。**改既有内容/标签（memo_update/tag_rename）先展示改动前后并等明确授权**，绝不静默覆盖或改名。
2. 带来源 URL 的卡，写入前该 URL 必须已真实抓取并基于实际内容写作；抓取失败/空 SPA 壳且无外链可追，禁止写云（不得凭域名臆测）。
3. 调 flomo 一律走 `python scripts/flomo_client.py <tool> --file <json路径>`（从文件读 JSON，避 PowerShell 引号转全角）；不写内联 JSON。
4. 写云前必查重并显式报告结论（命中什么/无重复），不敷衍。
5. 复盘改动文档须附真实 commit hash，不口头虚称"已推送"。

## 卡片格式

首行 `#标签/细分` 单独成段，空一行接正文。下方为格式示意，**尖括号 `<...>` 是说明占位，落卡时一律替换为真实内容，且禁止把"一句话核心结论"等格式提示词当作正文前缀写进卡片**：

```
#标签/细分

<直接写结论句，例如：MotherDuck 于 2026-08-25 收购 Tower，补齐数据工程运行时>

要点：
- 要点一（依据）
- 要点二

来源: https://真实来源（资料卡保留）
```

- 结论先行：首段直接写结论句，**不要带"一句话核心结论："这类模板提示词前缀**（那是给模型看的格式说明，不是正文）。
- "要点："/"来源:" 是可保留的结构/出处标记；其它如"一句话核心结论："等纯说明性文字不得写入。
- 不设字数上限，压到够清楚即可。
- flomo 富文本实测：支持加粗 `**文字**`、高亮 `<mark>`、下划线 `<u>`、两级列表、空行分段；不渲染标题/引用/代码块/链接/表格/图片。
- 公式用 Unicode（∑ μ →），不写 LaTeX 美元符。来源行不加注释。

## 标签规则

- 首行标签段，多个 `#标签` 空格分隔；**每个带 `#`**，裸词不进标签系统。
- **子标签带主前缀**：`#思想/协调博弈`，不裸写 `#协调博弈`（会建出独立顶层）。
- **层级严格两级（硬限）**：标签形态仅 `#顶层/二级` 一种（例：`#科技/安全` `#思想/协调博弈`）。**禁止三级及以上**：`#科技/安全/邮件认证`、`#科技/安全/钓鱼` 这类三段路径一律非法。若主题看似需第三层，二选一：① 并入既有二级（如邮件认证/钓鱼/攻击面本就含在 `科技/安全` 定义内，直接落 `科技/安全`）；② 在合适顶层下新建二级（仍两级，需授权+现查）。宁在二级内用正文细分，绝不下探层级。
- 顶层禁泛指词头（`#概念/` `#方法/`）；禁 emoji/特殊字符；英文词用下划线（`#Apple_seed`）。
- 新顶层/二级前先 `memo_search`+`tag_tree` 现查近邻，能归入既有绝不新建；新建/重命名/合并标签（tag_rename）需授权。

## 顶层词表（新建前先查）

投资/ 金融/ 会计/ 量子/ 物理/ 科技/（科研体系、技术产业通论） AI/（大模型与 agent） 跑团/ 游戏/ 未竟/ 回环/ 媒体/（渠道层面） 思想/（协调理论、社会制度、社科机制思辨） 产业/ 政策/ 算力/（布局 战略 组织模式） 数字孪生/
**纯概念筐纪律**：`/方法论` `/概念` 只收元层面（研究框架、范式、通用方法），具体某政策/事件/产品/人物的当期解读一律落具体主题二级，严禁塞筐。

## 流程

1. **抓取**：webfetch 为主，SPA/清单站补 `curl -L -A "Mozilla/5.0"`；同名对象按域名/作者/用途消歧。
2. **提炼**：滤营销话术，留事实/数据/因果链，不编造。抽取主体对象的"可枚举状态/可量化指标"作**结构化状态字段**（空间/场所→占用/空置；组织/项目→活跃/停滞/终止；产品/服务→在售/下架/受限；政策→生效/搁置/废止），使跨卡可比对；状态须源自正文事实，不得臆测。
3. **定标签（含筐型判断，阻塞）**：`tag_tree` 现采完整树，命中既有簇。关键判断——**具体当期主题 ≠ 纯概念筐**：`/方法论` `/概念` 这类二级只收"研究怎么做"的元层面（框架、范式、通用方法），具体某政策/某事件/某产品的当期解读严禁塞入，必须落到具体主题二级（无则新建，需授权）。新建二级先现查近邻、确认无既有簇。标签深度严格两级，不得产生 `#顶层/二级/三级` 形式。
4. **查重（阻塞）**：`memo_search` 关键词扫 + `tag_tree` 列该主标签细分逐条比对（主标签维度检索常返回 0，须退回关键词+逐条比对）。无命中→新建；完全重复→指原卡；部分重叠→更新原卡。
5. **写作**：按卡片格式写 1 条；主体有可枚举状态时，「要点」后补一行 `状态：<状态>/<指标>`（非强制）。
6. **写云前自检（阻塞）**：`python scripts/validate_memo.py --content "..."` 须 EXIT=0（0 ERR）才许写云；任一项 ERR 先改再写，禁止把云端当草稿反复 memo_update。**自检通过即调 memo_create 写云，免确认**（判定以脚本 `[成功] 已写入 memo id=` 为准）。质检脚本强制标签严格两级（三级及以上/裸顶层直接判 ERR），与「标签规则」硬限同源。
7. **复盘（写卡后必做，须现查）**：`memo_search` 关键词扫近邻 + `tag_tree` 列同主标签细分，逐一判断：
   - **错配核查（先看）**：本卡标签是不是具体主题误塞进 `/方法论` `/概念` 等纯概念筐？是→提议建具体二级并 `memo_update` 改标签（需授权），不得自欺写"归入既有"。
   - 标签归并（真可行）：两卡仅标签命名不同、本质同类 → 提议 `tag_rename`，需授权。
   - 内容聚合（只提议）：与既有卡实质重叠 → 提议"并入某卡，源卡留待你手动删"，绝不声明已合并。
   - 确无近邻：写明"已现查 tag_tree+关键词，无需调标签或聚合"。禁止只写"本轮无 memo 需更新"。
   - **复盘建议禁区（硬限）**：第 7 步收尾输出的「常规 + 创新」两条建议，落点仅限 flomo 云端卡片（标签聚类成簇、新建方法观察卡、聚合既卡），**严禁提议改动 SKILL.md / AGENTS.md / 顶层词表 / 脚本等技能文档**；词表补登、文档修订等不混入复盘建议，须等用户另行指令或走独立改动流程（commit+真实 hash+push）。复盘不得涉及关联卡片（`linked_memos` 单向链接）。
8. **更新云端（需授权）**：定位通读→展示改动前后→`memo_update`（覆盖式）或 `tag_rename`。无需求明示"本轮无 memo 需更新"。

## 写成功判定（防重复写）

`flomo_client.py` 写操作后强制从 `result.structuredContent.id` 取 id，stderr 打印 `[成功] 已写入 memo id=...`；取不到则 `[失败]` 且退出码非 0。**判定依据唯一**：脚本退出码 0 + stderr 出现 `[成功] 已写入 memo id=`。退出码非 0 一律按失败，绝不重发。

## 对接细节

- 端点 `https://flomoapp.com/mcp`，Bearer 鉴权（token 在 .mcp.json）。本环境无 MCP 面板，统一走 flomo_client.py 直连。
- `memo_create(content；format 可选 markdown/html，省略即纯文本)`；`memo_update(id/content)`；`tag_rename(old_tag/new_tag/max_memos)`。依赖 flomo Max 会员。
- 结构化链接 `linked_memos` 仅 `memo_create` 可设；`memo_update` 拒绝该字段；正文 `((memo_id))` 不被解析为链接。给已有卡补链只能删旧建新或 App 手动。
- 正文防标签误识别：flomo 扫全文 `#xxx`/`/xxx` 当标签。写前预判改写——`#8435`→"issue 8435"、`≤#150`→"第150位"、`C#/.NET`→空格或"与"连接。

## 本地与治理

- 仓库只存技能/配置文档，不含卡片正文；`.mcp.json` 已 gitignore。
- 改动走 commit + 自动 push，称"已提交/已推送"须附真实 hash。
- 改动后跑 `scripts/audit_skill.sh`（sounding linter，目标 100/100、0 findings）自校。
- 云端状态/机制不进 memory：标签树、卡清单、已写入规则均现查 SKILL.md 或 `tag_tree`，不记忆。
