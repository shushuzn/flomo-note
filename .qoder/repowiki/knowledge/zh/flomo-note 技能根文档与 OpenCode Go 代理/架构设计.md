模块由三份职责分离的文档与一个独立 Node.js 脚本组成：
- `README.md`：面向用户的“是什么 / 怎么跑 / 控制台怎么用”，不复制 SKILL 细则，仅引用编号；同时维护 scripts/ 与 tests/ 的职责表。
- `AGENTS.md`：8 条全局不可违背约定（云端不落盘、写云免确认、来源真实、SKILL 唯一细则源等），并定义改脚本 → 配套测试的维护契约与分层约束（cli_util 叶子、无环 import、FlomoError/UsageError 边界）。
- `ENVIRONMENT.md`：记录随机器/沙箱变化的事实（Ubuntu/Windows 双平台、Python 版本、`.mcp.json` token 优先级、HTTP_PROXY 502、GitHub DNS 劫持、SNI 阻断、技能注册到 dsh/OpenCode/Qoder Desktop 的路径）。
- `opencode-go-proxy.js`：独立的 Node.js 本地代理，监听 127.0.0.1:8787，自动补上 `x-opencode-session` 头并把请求原样转发至 `https://opencode.ai:443`，解决 OpenCode Go 表单只能走 OpenAI 兼容协议的问题；会话 ID 通过 `OCODE_SESSION` 环境变量注入，密钥可通过 `OPENCODE_KEY` 或表单 Authorization 头传入。
依赖方向单向：文档之间互引但不 import，`opencode-go-proxy.js` 是纯标准库实现，与 Python 工具链完全解耦。
